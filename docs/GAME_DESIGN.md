# 《星骸回声》垂直切片设计

## 游戏支柱

1. **能力驱动探索**：每项新能力同时改变移动、战斗和旧区域的可达路径。
2. **短而完整的回环**：17 个房间在 15–25 分钟内形成两次明确回访和三条捷径。
3. **清晰的战斗语言**：所有伤害都有预警、轮廓和音效反馈，不制造视野外攻击。
4. **孤寂但不晦暗**：环境叙事简短，关键目标始终可从地图和终端确认。

## 故事

回收员“伊娅”收到来自废弃观测站“星骸”的重复求救信号。站内生态实验体与防御系统已经融合，信号源“零点核心”仍在按照失控指令复制整座空间。伊娅需要重启两项外骨骼模块，抵达核心并关闭守核者。

## Boss

守核者 Λ 具有 30 点生命：

- 扇形能量弹：聚光线预警后朝玩家方向发射三至五枚弹体。
- 核心射线：玩家所在高度先出现贯穿房间的半透明预警线，随后短暂激活。
- 地面震波：核心下方先出现琥珀警戒区，随后向左右发射贴地能量波。
- 生命低于 50% 后缩短招式间隔并交替组合，但任何时刻只存在一种直接伤害判定。
