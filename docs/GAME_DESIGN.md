# 《星骸回声》垂直切片设计

## 游戏支柱

1. **能力驱动探索**：每项新能力同时改变移动、战斗和旧区域的可达路径。
2. **短而完整的回环**：17 个房间在 15–25 分钟内形成两次明确回访和三条捷径。
3. **清晰的战斗语言**：所有伤害都有预警、轮廓和音效反馈，不制造视野外攻击。
4. **孤寂但不晦暗**：环境叙事简短，关键目标始终可从地图和终端确认。

## 故事

回收员“伊娅”收到来自废弃观测站“星骸”的重复求救信号。站内生态实验体与防御系统已经融合，信号源“零点核心”仍在按照失控指令复制整座空间。伊娅需要重启两项外骨骼模块，抵达核心并关闭守核者。

## 战斗融合

- 带盾爬行体在闭合时免疫所有武器。相位冲刺越过其中心会在玩家抵达侧暴露核心 1.8 秒，最后 350ms 闪烁预警。
- 能量刃总判定 105ms，前 80ms 可反射炮台弹和守核者扇形弹。反射弹反向加速至 1.25 倍、造成 2 点伤害。
- 实际墙跳会武装一次首发贯穿弹。贯穿弹保持 1 点伤害，可命中多个普通敌人，但被墙、闭合护盾与 Boss 阻挡。
- 普通枪击造成约 24ms 命中停顿与 100ms 硬直；能量刃、贯穿和反射造成约 38ms 停顿与 160ms 硬直。

完整判定、教学和验收记录见 [`COMBAT_FUSION_V0.2.md`](COMBAT_FUSION_V0.2.md)。

## Boss

守核者 Λ 具有 30 点生命：

- 扇形能量弹：聚光线预警后朝玩家方向发射三至五枚可反射弹体。
- 核心射线：玩家所在高度先出现贯穿房间的半透明预警线，随后短暂激活。
- 地面震波：核心下方先出现琥珀警戒区，随后向左右发射贴地能量波。
- 生命低于 50% 后缩短招式间隔并交替组合，但任何时刻只存在一种直接伤害判定。
