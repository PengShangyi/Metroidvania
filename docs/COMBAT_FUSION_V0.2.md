# `v0.2.0` 战斗融合规则与试玩记录

## 设计目标

`v0.2.0` 不增加按键、装备、货币或存档字段，而是让相位冲刺、能量刃、磁附跃迁和能量枪互相产生战斗用途。`star-echo.save.v1` 与 `v0.1.0` 完全兼容。

## 三项融合机制

### 冲刺穿盾开核

- `shielded` 变体只允许用于爬行体；主世界固定放置于封锁堤道、孢流入口和静滞门槛。
- 闭合护盾格挡普通枪、贯穿弹、能量刃和反射弹；冲刺本身不造成伤害。
- 玩家必须在冲刺状态下与盾兵重叠并越过其中心，普通接触不会开盾。
- 核心在玩家抵达侧暴露 1.8 秒，最后 350ms 闪烁；只有来自核心侧的命中有效。
- 盾兵生命为 2。能量刃或反射弹可一次击杀，普通枪或贯穿弹需要两次有效命中。

### 能量刃短窗反射

- 挥砍判定总长 105ms，前 80ms 可反射炮台弹与守核者扇形能量弹。
- 射线、地面震波、接触与环境伤害不可反射；反射判定先于同帧玩家受伤判定。
- 反射后弹体速度向量完全反转并乘以 1.25，阵营切为玩家，伤害变为 2，寿命重置为 1.8 秒。
- 同一挥砍可反射所有相交的合格弹体；每枚弹体只可反射一次，命中首个敌人或 Boss 后销毁。

### 墙跳首发贯穿

- 只有实际完成墙跳才递增墙跳序号；普通跳跃和墙滑不会武装贯穿。
- 每次墙跳武装一次首发，射击立即消耗；冲刺和近战不会取消。
- 落地、死亡、换房或重置状态会清除武装，再次墙跳会刷新。
- 贯穿弹保持 1 点伤害与原射速，可连续命中普通敌人及已暴露核心；同一目标最多结算一次。
- 墙体、闭合护盾和 Boss 会阻挡贯穿弹。青色长弹体、琥珀核心及玩家琥珀轮廓表示当前状态。

## 命中反馈

| 命中类型 | 停顿 | 敌人硬直 | 反馈                     |
| -------- | ---: | -------: | ------------------------ |
| 普通枪击 | 24ms |    100ms | 轻击退、青色火花         |
| 能量刃   | 38ms |    160ms | 强击退、苍白火花、轻震屏 |
| 贯穿弹   | 38ms |    160ms | 强击退、琥珀火花、轻震屏 |
| 反射弹   | 38ms |    160ms | 强击退、青色火花、轻震屏 |
| 穿盾开核 | 45ms |        — | 局部双层火花和开核音效   |

固定炮台和浮游敌人只做 2px 视觉后坐，不改变其关卡定位。所有震屏继续服从辅助设置；局部火花不触发全屏强闪光。暂停、死亡、换房和场景关闭都会恢复物理时间倍率并释放临时弹体。

## 教学与提示

新手训练现为九步：移动、跳跃、双武器、反射、冲刺、穿盾开核、墙跳、墙跳贯穿、终端交互。反射课使用正式炮台弹，破盾课使用正式盾兵，贯穿课要求同一正式弹体命中两个正式敌人，不使用仅视觉成功的假判定。

主线在测绘仓、封锁堤道、垂直花塔首次进入时分别显示反射、破盾和贯穿提示。提示持续约 2.2 秒，仅在当前内存会话去重，不进入存档。Help 页的键鼠与手柄版本同步说明三项技巧。
