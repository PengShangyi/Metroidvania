# 《星骸回声》控制说明

## 键盘与手柄

| 动作     | 键盘                 | Xbox 风格手柄  | 说明                                       |
| -------- | -------------------- | -------------- | ------------------------------------------ |
| 移动     | `A` / `D` 或 `←`/`→` | 左摇杆 / D-pad | 地面加速，松开后快速减速                   |
| 跳跃     | `Space`              | A              | 短按低跳、按住高跳；含跳跃缓冲与土狼时间   |
| 能量枪   | `J`                  | X              | 1 伤害；墙跳后的第一发变为贯穿弹           |
| 能量刃   | `K`                  | Y              | 2 伤害；挥砍前 80ms 可反射合格弹体         |
| 相位冲刺 | `Shift`              | B              | 空中一次、全程无敌、450ms 冷却；可穿盾开核 |
| 交互     | `E`                  | RB             | 同步终端、读取残留记录（通道走进去即可）   |
| 地图     | `Tab`                | View           | 打开或关闭已探索房间地图                   |
| 暂停     | `Esc`                | Menu           | 打开暂停菜单；子菜单中返回上一级           |
| 帮助     | `H`                  | LB             | 随时打开与关闭自适应控制说明               |
| 全屏     | `F`                  | —              | 切换浏览器全屏                             |

手柄支持运行中连接和断开；断开后键盘可立即接管。Help 页根据最近一次实际输入自动显示键鼠版或手柄版，不会仅因手柄处于连接状态而误切换。窗口失焦会自动暂停并清除残留输入。

标题页的“新手训练”提供独立九步教学，依次演示移动、可变高度跳跃、双武器、短窗反射、相位冲刺、穿盾开核、磁附跃迁、墙跳贯穿和终端交互；训练过程不会覆盖正式存档。

## 移动技巧

- 离开平台边缘后的 100ms 内仍可起跳；提前最多 120ms 按下跳跃会在落地时自动触发。
- 取得相位冲刺后，空中冲刺次数会在落地时恢复。冲刺可穿过标有青色相位纹路的窄门。
- 取得磁附跃迁后，贴墙下落会限制为 55px/s；面向墙壁按跳跃可向反方向跃出。
- 冲刺越过带盾爬行体的中心会在抵达侧暴露核心；从错误侧攻击仍会被格挡。
- 能量刃挥砍前 80ms 可反射炮台弹和 Boss 扇形弹；射线与震波不可反射。
- 墙跳会武装一次贯穿射击，琥珀轮廓表示可用；首次射击、落地、死亡或换房会清除。
- 能量枪适合边移动边压制，能量刃适合反射与核心处决。受伤后有 650ms 无敌时间。

## 菜单与辅助选项

鼠标仅用于标题页和菜单，不参与游戏内瞄准。当前版本不支持触屏或按键重绑。

暂停菜单包含：

- 主音量：0%、25%、50%、75%、100%。
- 屏幕震动：关闭后不再触发受伤和 Boss 震屏。
- 强闪光：关闭后保留轮廓预警，但不使用全屏强闪。

游戏使用 480×270 逻辑画布、最近邻缩放和 16:9 FIT；默认 960×540 显示，改变窗口尺寸不会改变物理数值。
