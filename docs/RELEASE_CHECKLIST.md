## 界面分辨率提升

验收日期：2026-08-02（Europe/London）

基线环境：macOS、Node.js 24.18.0、pnpm 11.9.0

起因是界面在 480×270 下的三个问题：文字被遮挡、清晰度不足、中文辨识度低。
做法是把界面与世界解耦，而不是整体抬分辨率——后者要重做关卡可达性。

- [x] **画布升到 960×540，世界层保持 480×270**。`play` 与 `tutorial` 挂 `camera.zoom = 2`，
      于是 `rooms.json`、`MOVEMENT`/`DASH`/`WALL_JUMP`、`reachability` 包络与全部世界美术零改动，
      `roomGeometry.test.ts` 与 `mapLayout.test.ts` 一行没动。
- [x] **界面改用双字体**。定宽内容（数值、Boss 血条菱形、按键胶囊）留在 Fusion Pixel 12
      并只用 12 的整数倍字号；成段中文改用 Noto Sans CJK SC 的子集，中文笔画第一次真正清楚。
- [x] **布局锚点集中到 `ui/layout.ts`**，不是把旧坐标 ×2。多出来的空间用于：帮助面板说明列
      从约 145px 加宽到 224px（`helpContent` 里为硬挤而设的 `compactAction` 缩写整个删掉）、
      地图底部的逗号串换成带色块的真图例、结局的叙事段落与数值列拆开。
- [x] **立绘按 186×384 原生尺寸绘制**，此前是 `setDisplaySize(111,229)` 的 0.597 倍分数重采样。
- [x] **标题图重新导出为 960×540**（源图 1672×941，仍是降采样）；三张区域背景保持 480×270。

### 期间修掉的缺陷

- [x] **中文完全不换行**：Phaser 默认按空格断行，一整句中文被当成一个超长单词冲出画布两侧。
      新增 `wrapProse` 统一走 `advancedWordWrap`。
- [x] **常驻 HUD 会从覆盖层面板底下透出来**并与地图返回键撞版。
- [x] **训练完成面板底下的头部信息带没有藏起来**，撞上面板标题。
- [x] **「训练 1/9」从未显示**：进度行拿「初始状态」当 diff 基准，而首个真实状态与它完全相等。
- [x] **训练关没有物理边界**：此前靠 config 默认值兜底，画布一升玩家就能走出房间。

- [x] `pnpm assets:validate`：19 张运行时图像、瓦片接缝、图集与敌人贴图尺寸、背景尺寸表、两套字体。
      该命令本轮首次进入 CI —— 此前完全不在流水线里，校验和与许可证检查等于没有约束力。
- [x] `pnpm test:e2e`：Chromium、Firefox、WebKit 共 39 项旅程。
- [x] 运行时图像 1.14MB / 20MB，生产首屏 2.30MB / 8MB（新增 305KB 正文字体子集）。
- [x] 生产构建扫描确认不存在 `__STAR_ECHO_TEST__`。

### 新增的回归防线

- **排版断言从 4 屏扩到 13 屏**：补上游戏内 HUD、提示条、Boss 血条、地图/暂停/设置/帮助
  四个覆盖层与结局。上面那三个撞版缺陷都是被这次扩面当场抓到的。
- **`zoomedTexts`**：任何文本一旦回到 zoom 2 的世界场景，e2e 立刻报出那句话。
- **`offGridPixelFontSizes`**：像素字用了非 12 整数倍字号即失败。
- **`minimumFontSizeByFamily`**：像素字 ≥24、矢量字 ≥16，单一全局下限表达不了这件事。
- **`fontCoverage.test.ts`**：正文字体是按用字做的子集，源码里新增一个汉字而不重跑
  `pnpm art:font` 就会渲染成豆腐块；这条测试在 `pnpm check` 里把缺字直接列出来。
- **训练关边界旅程**：按住方向键跑到位置不再变化，断言 x ≤ 480。去掉 `setBounds` 时实测得到 953。
- 以上五条均已通过「故意改坏 → 确认报错」验证过。

## 玩法修复与美术接入

验收日期：2026-08-01（Europe/London）

基线环境：macOS、Node.js 24.18.0、pnpm 11.9.0

本轮的目标是修掉一批真实缺陷、把「能力门」从门禁卡变回地形挑战，
并把仓库里早就画好却从未被加载的美术接进游戏。

### 修复的缺陷

- [x] **跳不到的平台**：实测最大跳跃上升是 47.5px（Arcade 的半隐式 Euler 比解析式少半帧），
      而十处平台落差正好是 48px，只靠 4px 的重叠容差才勉强判定为落地。统一降到 44px。
- [x] **悬在半空的门**：`bioforge_spire.to_reactor` 与 `reactor_coreway.to_threshold` 的判定区
      前方没有落脚平台（平台止于 x=410，门在 438），拿齐两项能力也进不去。
- [x] **冲刺没有冷却**：落地即刷新，贴地连按可维持约 250px/s（走路 110），无敌覆盖率近七成。
      改为 450ms 冷却驱动，并把无敌时长提到与冲刺等长（原先最后 30ms 会掉血，与穿盾教学冲突）。
- [x] **教学软锁**：反射课与贯穿课的训练体可以被打死，而完成信号来自 COMBAT_EVENTS，
      靶子没了就再也触发不了；敌人死光后玩家也不会再受伤，唯一的恢复路径走不到。
- [x] **存档可致白屏**：hydrate 不校验房间 id，未知 id 会让 `PlayScene.preload` 抛出未捕获异常。
- [x] **地图进度丢失**：换房不写存档，两次写入之间探索的房间会从 `visitedRooms` 里消失。
- [x] 爬行体无悬崖检测、炮台无索敌范围、近战判定框不跟随玩家、无敌帧仍会吞掉弹体、
      Boss 弹幕不与地形碰撞、换房后残留跳跃缓冲。

### 银河城结构补强

- [x] **地图战争迷雾**：原先开局就画满 17 个房间和全部连接。现在分「走过 / 见过门 / 未知」三档，
      并在走过的房间上标出终端、未取道具与能力门。未取得的能力模块是第四类标注，
      它不受「走过」约束——那是主线目标，藏起来只会让被能力门挡住的玩家不知道往哪走。
- [x] **走入通道即换房**：去掉「按 E 过门」，E 只保留给终端和残留记录；
      落在返回出口判定区里的两个生成点用「出口武装」机制避免原路弹回。
- [x] **能力门地形化**：封锁堤道改成 88px 的酸蚀断口，走跳最远 71.5px，必须冲刺才过得去。
      （最初定的 104px 只留下不到 1px 的起跳窗口，见 `world/hazardCrossing.ts`。）
- [x] **Boss 前与生化区后半增设终端**：原先 Boss 失败要重跑四个房间，花塔死亡要退回孢流入口。

### 美术

- [x] 四只敌人的立绘早就画好却零引用，游戏一直在渲染程序化的三角形和矩形；
      新脚本按 alpha 列投影自动切图并派生护盾/开核变体。
- [x] 主角 19 帧原先是十来条 `rect()` 拼的色块，帧间只差 1-2px，视觉上「不动」；
      改为从去背原画派生，跨步、残影、真溶解都做出来了。
- [x] 前庭六个房间（开局区域）补上 16px 无缝地块，地形不再是纯色矩形。
- [x] 标题页接上主角立绘（此前 `textures.exists` 分支永远走不到）。
- [x] 背景图 + 雾层 + 描边网格三层叠加把手绘背景压得几乎看不见，重新调参。

### 自动验证

- [x] `pnpm check`：格式、lint、类型检查、32 个 Vitest 文件 / 141 项测试、生产构建与加载预算。
- [x] `pnpm assets:validate`：19 张运行时图像、瓦片接缝、图集与敌人贴图尺寸、20MB 总量。
- [x] `pnpm test:e2e`：Chromium、Firefox、WebKit 共 33 项旅程。

- [x] 生产构建扫描确认不存在 `__STAR_ECHO_TEST__`。

### 新增的回归防线

- **几何可达性模型**（`world/reachability.ts`）：按 `MOVEMENT`/`DASH`/`WALL_JUMP` 的常量
  逐帧模拟 Arcade 的半隐式 Euler 推出运动包络，再对房间平台图做 BFS。
  保守包络断言「必须走得通」，宽松包络断言「没有能力必须走不通」。
  这一层此前完全缺失——旧的可达性校验只看能力门的布尔值，e2e 又全靠 `warp` 瞬移换房，
  所以跳不到的平台和悬空的门从来没有被任何测试碰到过。
- **地形门不许退化**：断言当前四道真正靠几何拦住玩家的门。
- **世界计数单一来源**：`COMPLETION_TOTAL` 与 `rooms.json` 的实际计数一致。
- **走过一扇门的浏览器旅程**：整个套件里第一条真正用键盘穿过通道的测试。
